## OBJETIVO:
Projeto 4 — Cardápio Digital de Restaurante
Cliente: Sabor & Código
Descrição: Restaurante de comida quer canal próprio.
Problemas a solucionar:
Página inicial com identidade do restaurante
Cardápio completo por categorias (Entradas, Principais, Sobremesas, Bebidas)
Cada prato: nome, descrição, preço, foto, indicador vegetariano/vegano
Destaque para pratos do dia
Página "Sobre Nós" com história
Formulário de reserva de mesa: nome, data, horário, pessoas, observações
Botão de WhatsApp visível em todas as páginas
Visual aconchegante (vermelho, marrom, laranja, tons de madeira)
Cardápio legível e funcional no celular (principal canal de acesso)
Identificação clara de restrições alimentares (glúten, lactose)
